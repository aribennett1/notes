Privacy Policy

Last updated: November 19, 2026

How Private Notes works

Private Notes uses Firebase Authentication and Google Sign-In to authenticate the user. A Firebase ID token authorizes requests to the application's storage API.

Your notes and encryption

Note contents are encrypted in your browser before they are uploaded. The application uses a master password only in the browser to derive encryption material and encrypt or decrypt the workspace. Plaintext notes and the master password are not transmitted to Google Cloud Storage.

The storage service receives an encrypted workspace file and encryption metadata required to decrypt it locally. It does not receive readable note content or your encryption password.

Storage and authentication

Encrypted notes are stored in Google Cloud Storage. A Cloud Run API verifies the signed-in account and uses its service identity to access the bucket. The application does not use third-party analytics.

An encrypted local cache of the workspace may be retained in your browser using IndexedDB. Firebase Authentication retains a browser session to restore sign-in on later visits.

Your responsibilities

Keep your master password secure. If it is lost, encrypted notes may be unrecoverable. Use a trusted device and lock the application when you finish. No web application can protect plaintext while it is open in a compromised browser or device.
